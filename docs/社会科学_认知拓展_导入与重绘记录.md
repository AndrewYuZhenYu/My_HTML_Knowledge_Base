## 两种重绘的边界

1. **独立交互重绘（43 个）**：`tools/social_widgets.py` 配置知识点、参数和原图对应关系；`assets/social-widgets.js` 用自身的 SVG 绘制函数、计算模型与步骤控件生成图像。组件直接位于原图的知识点位置。无 JavaScript 时，展开的静态矢量重建图仍可阅读。
2. **矢量重建（680 张，含交互图的静态底图）**：`tools/redraw_social_vectors.py` 从 ZIP 的 SVG 提取几何、文字和连线，按网站色彩与字体重新输出 SVG。发布页面引用 `assets/social-redrawn/` 中的新文件。此过程保留原图的数据、节点和布局，属于自动化的视觉重建，**不是**对每一张图进行独立的数据核算或从零设计。原始图保存在 `sources/social-sciences/_assets/` 供审查。
3. **两张原始 JPG**：投资笔记中的交易软件日线图和分时图保留在 `sources/` 用于溯源。股票投资试点已将其主阅读位置改为原生网页行情面板；只录入截图可辨认的数值，没有凭空再造历史行情。详见 [股票投资网页原生化试点](股票投资_网页原生化试点.md)。

这一区分很重要：不能把 680 张统一视觉的再输出说成 680 张经过独立科学复核的图。43 个可调组件是本轮真正独立实现的模型。它们中的虚构数值、假设和公式限制已写在图注，不应作为实际法律、投资、心理诊断结论。

## 接入和重复构建

- ZIP 遴选和安全导入：`tools/import_social_zips.py`，具体源 ZIP 的校验摘要在 `docs/social-archive-import-report.json`。
- 680 张静态 SVG 的重新生成：`tools/build.py` 在处理社会科学图像时调用 `tools/redraw_social_vectors.py`，无需手工拷贝。引用采用相对路径，兼容本地打开和 GitHub Pages 的项目子路径。
- 43 个交互图通过原图文件名前缀准确定位，并替换到正文对应段落。若图位消失或重复，构建直接报错。18 个旧 Obsidian HTML 演示链接已指向页面内对应组件。
- `python tools/build.py --check` 校验标题、数学式、图数和本地链接；`python tests/smoke.py` 校验全部社会科学图位与组件；`node tests/social_widgets.cjs` 校验关键公式；`python tools/check_site_integrity.py` 扫描静态资源和页面链接。

## 模型示例及教学假设

- 复利：`FV = PV(1+r)^n`，默认无追加投入、费用与税收。参考 [Investor.gov 的复利说明](https://www.investor.gov/additional-resources/information/youth/teachers-classroom-resources/what-compound-interest)。
- D’Hondt：每轮按各党票数除以当前席位数加一，分配最高商值。演示票数是虚构的，不含门槛和特别选举规则。参考 [英国选举委员会的选举方式说明](https://www.electoralcommission.org.uk/voting-and-elections/how-elections-work/types-elections/voting-senedd-elections)。
- 折旧、NPV、EOQ、损益平衡：由图中的参数重新计算；除特别说明外均采用线性、确定现金流或恒定成本的教学假设。
- 供需、洛伦兹、正态分布、贝叶斯后验与抽样误差：用可检查的数学函数绘制，图注明确数据为模拟值或近似值。
