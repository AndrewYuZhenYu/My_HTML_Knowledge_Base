## 图位改造

本章原有 99 个图位：97 个 SVG、2 张手机行情截图。主阅读页现在不展示那两张截图，也不再直接用 `<img>` 显示其余非交互配图。

| 网页内形式 | 数量 | 处理方式 |
| --- | ---: | --- |
| 内联 SVG 图形 | 88 | 把重建后的矢量元素直接嵌入 HTML；文字可选取，并提供“复制图中文字”按钮。每张图的 SVG ID 独立命名，避免连线、裁剪和图标引用串图。 |
| JavaScript 绘制的行情面板 | 3 | 虚构示例行情可拖动观察时点；两张真实截图以可辨认字段制作简洁面板。 |

因此 99 个图位都有网页内的主要呈现形式。6 个交互图的折叠区仍留有静态矢量回退，供禁用脚本时阅读；它们不作为正文主图。原始 JPG 仍留在 `sources/` 供溯源，没有被裁剪覆盖或删除。

## 试点验收规则

1. 可用 HTML 表格表达的数据必须成为真正的表格，表头、单元格和单位可选择、可复制；复制按钮输出制表符分隔数据。
2. 能由 SVG/Canvas/HTML 编程表达的图，主阅读位置使用网页元素。具有可调关系的知识点应提供参数或步骤交互；静态 SVG 的文字至少可由按钮复制。
3. 手机截图只作为溯源素材保存在源目录；主阅读页清除状态栏、广告、底部导航等无关界面，保留可辨认且教学需要的数值。
4. 不从静态截图臆造逐笔行情、历史 OHLC、实时数据或未显示的单位。示例数组必须明确标为虚构示意。
5. 构建可重复，图位匹配错误直接失败；发布前检查图数、复制功能、资源链接和无脚本回退。

## 截图处理与数据边界

- 分时截图只录入可辨认的最新价、昨收、开盘、最高、最低、均价、成交额、换手率、量比、估值及涨停字段。网页图显示这些价位的横向比较，**没有伪造逐笔曲线**。
- 日线截图只录入可辨认的最新价、MA5/10/20/30、图示低点、午间量及 MACD 读数。网页图比较这些截面数值，**没有伪造历史每日 OHLC**。
- 盘口表保留截图中的“5.30 万”等原显示单位，并提示具体单位须以行情软件设置为准。最高封单额与涨停成交额分行展示，避免把已成交金额误认为挂单。
- “示例科技”原图本身写明是虚构行情。该图现由本地数组和 JavaScript 绘制，并标注虚构示意；滑块控制显示时点，不连接实时行情。

## 构建与验证

`tools/investment_native.py` 在构建时把本章图位转为内联 SVG、HTML 表格或行情面板，`assets/investment-native.js` 负责示例曲线、截图数值图和复制按钮，样式在 `assets/style.css`。只修改生成逻辑即可重复构建，不需逐个编辑生成页。

验证命令：`python tools/build.py --check`、`python tests/smoke.py`、`node tests/investment_native.cjs`、`python tools/check_site_integrity.py`。冒烟测试检查 93 个原生网页图、2 张表、88 个内联 SVG、3 个行情面板和阅读页不含 JPG；JavaScript 测试检查示例滑块及表格、字段、图中文字复制。浏览器环境对本地 `file:` 自动预览有访问限制，因此没有把实际浏览器视觉效果列为已验证。
