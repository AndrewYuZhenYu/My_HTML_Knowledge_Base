第三章　栈和队列

学习定位

栈与队列都是运算受限制的线性表，本章不仅要记住 LIFO、FIFO，还要能够跟踪每一次插入、删除、数组下标移动、链指针修改以及递归调用栈的变化。对于“执行过程”，每组插图都是按实际算法状态重新绘制的，不是将文字塞进框中。

1. 栈和队列究竟限制了什么

在线性表中，可以在许多合法位置插入或删除元素。栈把插入、删除都约束在同一端，队列则在队尾插入、队头删除。因此，二者的区别不在于底层是数组还是链表，而在于操作规则。

比较项目 栈（Stack） 队列（Queue）
数据组织原则 后进先出，LIFO 先进先出，FIFO
插入位置 栈顶 top 队尾 rear
删除位置 栈顶 top 队头 front
典型场景 撤销、括号、表达式、递归、回溯 任务排队、缓冲、广度优先处理

图 155　栈和队列对比。

一个贯穿全章的区别 逻辑结构 只描述允许执行哪些操作； 存储结构 决定操作在内存中怎样实现。顺序栈、链栈的出栈次序相同；循环队列、链队列的出队次序也相同。

逻辑结构只描述允许执行哪些操作；存储结构决定操作在内存中怎样实现。顺序栈、链栈的出栈次序相同；循环队列、链队列的出队次序也相同。

2. 栈：定义、基本运算与出栈序列

2.1 栈的定义

设栈从栈底到栈顶为 。 是最先进入的元素， 是当前栈顶。只允许在 一端执行 Push 和 Pop。

  • InitStack：构造空栈。
  • DestroyStack：销毁栈的存储资源。
  • ClearStack：清空元素，保留可复用的栈对象。
  • StackLength：返回元素个数。
  • StackEmpty：判断是否为空。
  • GetTop：只读取栈顶，不删除。
  • Push：将一个元素压入栈顶。
  • Pop：删除并返回栈顶元素。
  • StackTraverse：按照指定顺序访问元素。

这些名称用于表达抽象数据类型的接口，实际 C++ 可使用 std::stack 或自行封装。

2.2 出栈序列不是输入序列的任意排列

假定输入顺序固定为 1 → 2 → 3。每次只能压入下一个尚未输入的元素，或者弹出当前栈顶。例如输出 2,3,1 可行，过程是 Push(1), Push(2), Pop(2), Push(3), Pop(3), Pop(1)。输出 3,1,2 则不可能：要先弹出 3，就必须先把 1、2 压在它下面，而弹完 3 后，2 必先于 1 出栈。

判断出栈序列的通用办法

按要求输出的序列逐个检查：如果栈顶不是所需元素，就把后续输入元素依次压栈；若所有元素已经输入，栈顶仍不匹配，则该出栈序列不可能。

3. 顺序栈：把抽象操作落实为数组变化

3.1 top 两种含义必须分清

教材展示过两套顺序栈表示法，最常见的区别是 top 的含义。

  • 约定 A：指向当前栈顶元素的下标。 空栈 top=-1；压栈执行 data[++top]=x；出栈执行 x=data[top--]。
  • 约定 B：指向栈顶之后的下一个空位置。 空栈 top=0（或指针 top=base）；压栈执行 data[top++]=x；出栈执行 x=data[--top]。

容易混淆的细节

这两套约定都正确，但同一段算法不能混用。教材顺序栈的部分片段中采用 top=-1，另一部分采用 top=base，判断空栈和操作自增、自减时一定先确认所处的实现。

3.3 固定容量顺序栈的 C++ 实现

C++
#include <array>

class SeqStack {
private:
    std::array<int, 100> data{};  // 固定容量 100
    int top = -1;                 // top 指向栈顶元素

public:
    bool empty() const {
        return top == -1;
    }

    bool full() const {
        return top == 99;
    }

    int size() const {
        return top + 1;
    }

    bool push(int x) {
        if (full()) return false; // 防止数组越界
        data[++top] = x;          // 先修改 top，再写数据
        return true;
    }

    bool pop(int& x) {
        if (empty()) return false;
        x = data[top--];          // 先读取，再移动 top
        return true;
    }

    bool getTop(int& x) const {
        if (empty()) return false;
        x = data[top];            // 不改变 top
        return true;
    }
};

上溢表示固定容量栈已满还企图入栈；下溢表示空栈仍企图出栈。它们是操作前置条件不满足，而不等于“机器突然没有内存”。

4. 链栈：为什么入栈必须先连接旧栈顶

链栈通常让 top 指向第一个实际数据结点，不必专门设置头结点。链栈插入新元素就是链表头插法在栈顶位置上的应用；出栈就是删除第一个实际结点。

4.1 入栈与出栈的逐指针轨迹

  1. 创建新结点 p 并填写 p->data=x。
  2. 执行 p->next=top，先把新结点连接到旧链表。
  3. 执行 top=p，再让栈顶指向新结点。
  4. 弹栈时先令 p=top 保存旧栈顶，再 top=top->next，取值后释放 p。

指针顺序写反会丢链

不能先令 top=p 再写 p->next=top，否则新结点可能指向自己，旧栈顶链条丢失。删除结点时也不能先 delete top 再读 top->next，那会访问已释放的内存。

4.2 链栈的核心 C++ 代码

C++
struct Node {
    int data;
    Node* next;
};

bool push(Node*& top, int x) {
    Node* p = new Node{x, top};  // p->next 先指向旧 top
    top = p;                     // top 再改为新结点
    return true;
}

bool pop(Node*& top, int& x) {
    if (top == nullptr) return false;
    Node* p = top;               // 保存旧栈顶
    x = p->data;                 // 读取待删除的数据
    top = p->next;               // 保留其余结点的入口
    delete p;                    // 安全释放旧栈顶
    return true;
}

void clear(Node*& top) {
    int ignored;
    while (pop(top, ignored)) {  // 逐一回收结点
    }
}

链栈一般没有预先规定的固定最大容量，但仍可能因内存分配失败无法入栈。每次操作仅修改少量指针，因此时间复杂度为 。

C++
#include <string>
#include <vector>
#include <algorithm>

std::string toBase(unsigned int n, unsigned int base) {
    const std::string digits = "0123456789ABCDEF";
    if (base < 2 || base > 16) return "";
    if (n == 0) return "0";
    std::string result;
    while (n > 0) {
        result.push_back(digits[n % base]); // 低位先产生
        n /= base;
    }
    std::reverse(result.begin(), result.end()); // 模拟逆序出栈
    return result;
}

6. 栈的应用二：括号匹配

核心规则是：遇左括号压栈；遇右括号时，它只能与当前栈顶的左括号配对。扫描结束时，栈必须为空。错误有三种：右括号多余、类型不匹配、左括号遗留。

C++
#include <stack>
#include <string>

bool bracketsValid(const std::string& s) {
    std::stack<char> st;
    for (char ch : s) {
        if (ch == '(' || ch == '[' || ch == '{') {
            st.push(ch);
        } else if (ch == ')' || ch == ']' || ch == '}') {
            if (st.empty()) return false;             // 右括号多余
            char open = st.top();
            st.pop();
            if (ch == ')' && open != '(') return false;
            if (ch == ']' && open != '[') return false;
            if (ch == '}' && open != '{') return false;
        }
    }
    return st.empty();                                // 排除左括号多余
}
匹配判断 [(]) 错在类型嵌套不匹配； ()) 错在多余右括号； (([]) 错在左括号未配完。算法的时间复杂度为 ，辅助空间最坏为 。

C++
#include <string>

std::string editLine(const std::string& input) {
    std::string buffer;             // 使用字符串尾部模拟栈顶
    for (char ch : input) {
        if (ch == '#') {
            if (!buffer.empty()) buffer.pop_back();
        } else if (ch == '@') {
            buffer.clear();
        } else {
            buffer.push_back(ch);
        }
    }
    return buffer;
}
例子与约定 ab#c 的有效内容是 ac ； abc@xy 的有效内容是 xy 。 # 、 @ 是这一行编辑问题的自定义指令，不是现代编辑器普遍使用的文本语法。

8. 栈的应用四：迷宫回溯不是在“随意试路线”

典型**深度优先搜索（DFS）**总是沿一条当前可行路径尽量向前。当碰到无路可走时，利用栈回到最近一个还存在未试方向的位置。课程中的方向可按东、南、西、北依次尝试：

  1. 入栈：当前格可通行、未访问，把格子及下一候选方向记入路径栈。
  2. 继续探路：按固定的方向顺序试探下一个格子。
  3. 回溯：当前格的四个方向都试过，弹出该格，回到栈顶前驱。
  4. 结束：抵达出口则得到路径；栈空仍未抵达出口则无路可达。

“搜索访问过”与“最终路径”不同

死胡同在搜索时确实被访问过，但回溯后不会留在最终路径栈中。绘图用不同颜色标出当前路径与确认死路，不能把所有访问过的格子误认为答案路径。

C++
#include <vector>
#include <string>

struct Point { int r, c; };

bool findPath(const std::vector<std::string>& maze,
              int sr, int sc, int er, int ec,
              std::vector<Point>& path) {
    const int dr[4] = {0, 1, 0, -1}; // 东、南、西、北
    const int dc[4] = {1, 0, -1, 0};
    int rows = static_cast<int>(maze.size());
    if (rows == 0) return false;
    int cols = static_cast<int>(maze[0].size());
    std::vector<std::vector<bool>> used(rows, std::vector<bool>(cols, false));

    auto dfs = [&](auto&& self, int r, int c) -> bool {
        if (r < 0 || r >= rows || c < 0 || c >= cols) return false;
        if (maze[r][c] == '#' || used[r][c]) return false;
        used[r][c] = true;
        path.push_back({r, c});        // 相当于压入路径栈
        if (r == er && c == ec) return true;
        for (int d = 0; d < 4; ++d) {
            if (self(self, r + dr[d], c + dc[d])) return true;
        }
        path.pop_back();               // 四路不通，回溯
        return false;
    };
    path.clear();
    return dfs(dfs, sr, sc);
}

代码采用递归调用栈 + 显式路径向量来表达与教材迭代回溯等价的思想：调用栈保留“下一步尝试哪个方向”的信息，path 则保存仍在当前路线上的格子。为简化代码，假设迷宫各行等宽、起终点下标合法。

9. 栈的应用五：算符优先与双工作栈

求值 4+2*3-10/5，必须遵守“先括号、再乘除、后加减；同一优先级从左至右”的运算规则。

课程采用两个工作栈：

  • OPTR：运算符栈，保存尚未完成计算的运算符。
  • OPND：操作数栈，保存数字和中间结果。

读入操作数时直接压 OPND；读入运算符时比较其与 OPTR 栈顶的优先级。若栈顶运算符优先级不低于当前运算符，则先从 OPND 依次弹出右操作数 b、左操作数 a，计算 a op b，再将结果压回 OPND。若为左括号，先压入 OPTR；遇右括号，则规约到左括号，并弹出成对括号。

C++
#include <stack>
#include <vector>
#include <string>
#include <stdexcept>

int evalPostfix(const std::vector<std::string>& tokens) {
    std::stack<int> nums;
    for (const std::string& t : tokens) {
        if (t != "+" && t != "-" && t != "*" && t != "/") {
            nums.push(std::stoi(t));
            continue;
        }
        if (nums.size() < 2) throw std::invalid_argument("缺少操作数");
        int b = nums.top(); nums.pop(); // 先弹右操作数
        int a = nums.top(); nums.pop(); // 后弹左操作数
        int result = 0;
        if (t == "+") result = a + b;
        if (t == "-") result = a - b;
        if (t == "*") result = a * b;
        if (t == "/") {
            if (b == 0) throw std::domain_error("除数为零");
            result = a / b;             // 本例只演示整除结果
        }
        nums.push(result);
    }
    if (nums.size() != 1) throw std::invalid_argument("表达式不完整");
    return nums.top();

C++
#include <vector>
#include <cstdlib>

void solveQueens(int n, int row,
                 std::vector<int>& col,
                 std::vector<std::vector<int>>& answers) {
    if (row == n) {
        answers.push_back(col);             // 保存一个完整布局
        return;
    }
    for (int c = 0; c < n; ++c) {
        bool valid = true;
        for (int r = 0; r < row; ++r) {
            if (col[r] == c || std::abs(col[r] - c) == row - r) {
                valid = false;
                break;
            }
        }
        if (!valid) continue;
        col.push_back(c);                  // 进入下一层递归
        solveQueens(n, row + 1, col, answers);
        col.pop_back();                   // 回溯，恢复本层状态
    }
}

12. 队列的定义与基本操作

队列规定新元素只能从 rear 一端进入，旧元素只能从 front 一端退出。定义 时， 是队头， 是队尾。

常用的抽象操作包括 InitQueue、DestroyQueue、QueueEmpty、QueueLength、GetHead、ClearQueue、EnQueue、DeQueue 和 QueueTraverse。其中 GetHead 读取但不删除队头；DeQueue 则真正使队头离开队列。

13. 普通顺序队列为什么会发生“假溢出”

数组长度为 8，约定 front 指向当前队头数据，rear 指向下一可入队位置。初始 front=rear=0。入队使 rear++，出队使 front++。

若先放入 A,B,C,D,E，再出队 A,B,C，数组的前 3 个槽已经空闲，但 rear 仍在较右的位置。继续添加新元素直到 rear=8 后，即使前面的槽空着，仍无法直接入队；这是假溢出而不是真正占满了所有存储空间。

14.3 预留一格法的完整 C++ 实现

C++
#include <array>

class CircularQueue {
private:
    static constexpr int CAP = 8;
    std::array<int, CAP> data{};
    int front = 0;               // 指向当前队头
    int rear = 0;                // 指向下一个入队位置

public:
    bool empty() const {
        return front == rear;
    }

    bool full() const {
        return (rear + 1) % CAP == front;
    }

    int size() const {
        return (rear - front + CAP) % CAP;
    }

    bool enqueue(int x) {
        if (full()) return false;
        data[rear] = x;          // 先写再移动 rear
        rear = (rear + 1) % CAP;
        return true;
    }

    bool dequeue(int& x) {
        if (empty()) return false;
        x = data[front];         // 先读再移动 front
        front = (front + 1) % CAP;
        return true;
    }
};

先写物理容量 、当前 front/rear，判断操作合法性，再根据操作更新其中一个指针，每一步都取模。千万不要在“未预留空位的队列”和“预留一格的队列”之间混用判满公式。

15. 链队列：入队要改两个位置，删除最后一个元素更要谨慎

教材采用带头结点的链队列。front 指向头结点，rear 指向实际队尾结点；空队列时二者都指向头结点，头结点的 next 为 nullptr。

15.1 入队步骤

  1. 创建新结点 p，令 p->data=x、p->next=nullptr。
  2. 原尾结点的 next 指向 p：rear->next=p。
  3. 更新 rear=p。

15.2 出队步骤

  1. 先用 p=front->next 记住第一个实际数据结点。
  2. 更新 front->next=p->next，从链中越过 p。
  3. 如果 rear==p，说明删除的是唯一数据结点，必须让 rear=front。
  4. 读取并释放 p。

15.4 链队列 C++ 核心实现

C++
struct QueueNode {
    int data;
    QueueNode* next;
};

class LinkedQueue {
private:
    QueueNode* front;
    QueueNode* rear;

public:
    LinkedQueue() {
        front = new QueueNode{0, nullptr}; // 只作头结点
        rear = front;
    }

    ~LinkedQueue() {
        int x;
        while (dequeue(x)) {             // 释放所有实际数据结点
        }
        delete front;                    // 最后释放头结点
    }

    LinkedQueue(const LinkedQueue&) = delete;
    LinkedQueue& operator=(const LinkedQueue&) = delete;

    bool empty() const {
        return front == rear;
    }

    void enqueue(int x) {
        QueueNode* p = new QueueNode{x, nullptr};
        rear->next = p;                  // 先链接
        rear = p;                        // 再更新尾指针
    }

    bool dequeue(int& x) {
        if (empty()) return false;
        QueueNode* p = front->next;      // 指向首元结点
        x = p->data;
        front->next = p->next;           // 越过待删除结点
        if (rear == p) rear = front;     // 删除唯一元素时修正尾指针
        delete p;
        return true;
    }
};

该实现用头结点统一了“空队列”和“非空队列”的插入逻辑；为了避免浅拷贝引发重复释放，明确禁止复制。全部操作 。

#include <vector>
#include <stdexcept>
#include <climits>

// 返回 f_0 ... f_n 中最后的 k 项，满足 f_n<=limit, f_(n+1)>limit。
std::vector<long long> lastKTerms(int k, long long limit) {
    if (k < 2 || limit < 1) throw std::invalid_argument("参数范围非法");
    std::vector<long long> ring(k, 0);
    ring[k - 1] = 1;                    // f_(k-1)=1
    int oldest = 0;                    // 环形窗口的最旧项下标
    long long windowSum = 1;           // 当前 k 项之和 = 下一项
    while (windowSum <= limit) {
        long long next = windowSum;
        long long old = ring[oldest];   // 先保存即将被覆盖的值
        ring[oldest] = next;
        oldest = (oldest + 1) % k;      // 窗口向前移动
        if (windowSum > LLONG_MAX - next + old) {
            throw std::overflow_error("递推值过大");
        }
        windowSum = windowSum - old + next;
    }
    std::vector<long long> result;
    for (int i = 0; i < k; ++i) {
        result.push_back(ring[(oldest + i) % k]);
    }
    return result;
}
数值边界

这段代码把 limit>=1 作为前提，并使用 long long。若下一项超出整数范围，需要更严格的溢出保护或大整数类型。这里“容量恰好是 k”不意味着可以直接套用预留空格法，否则只存得下 项。

void reverseAccumulation() {

    std::cout << sum << '\n';

        sum += *it;
        std::cout << sum << '\n';
    }
}
